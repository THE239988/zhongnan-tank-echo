# 中南坦克 · 回响计划 3.0

基于提供的《试做1.0》继续开发的 **Java 17 + JavaFX 17 桌面游戏**。单人突围、本地双人对决、无尽回响、局域网多人混战和合作 Boss 均已接入可玩流程。本项目不使用网页技术替代 JavaFX。

## 启动

- **免配置 Windows 包**：解压 `TankTrouble-3.0-Windows.zip`，双击其中的 `run.bat`。内置精简 Java 17 运行时和 JavaFX，无需联网、无需安装 Maven。
- **当前源码目录**：双击 `run.bat`。有 JDK 17 时会先把最新源码编译到系统临时目录再启动，避免运行旧的 `target` JAR；没有 JDK 时回退到已有 JAR。
- **开发启动**：在本目录执行 `mvn javafx:run`。
- **独立联机服务器**：执行 `java -cp "target/tanktrouble-javafx-3.0.2.jar;target/lib/*" tanktrouble.App server 7777`。省略端口时使用 7777。
- **测试和打包**：`./test.ps1`、`./build.ps1`；也可直接执行 `mvn test`、`mvn package`。
- **界面回归**：`mvn test -DfxSmoke=true -Dtanktrouble.dataDir=target/test-data`。需要可用的 Windows 图形桌面，会打开独立测试窗口；截图在 `target/screenshots/`。

完整整合范围和验证记录见 `INTEGRATION-3.0.md`。

## 操作

| 操作 | 玩家 1 | 玩家 2（双人对决） |
|---|---|---|
| 前进 / 倒车 | W / S | ↑ / ↓ |
| 左转 / 右转 | A / D | ← / → |
| 开火 | 空格 | Enter |
| 共振脉冲 | Q | Shift |

单人还支持方向键移动和 Enter 开火。Esc 暂停或继续，B 打开战地补给。按住开火可连续射击；鼠标悬停在左下角键盘图标可查看按键。窗口失去焦点时自动暂停，防止切回游戏后按键卡住。

本地流程：首页「开始游戏」→ 准备页选择模式和坦克 →「开始游戏」进入战场。联机流程：首页「多人作战」→ 一名玩家启动本机服务器并创建房间 → 其他玩家输入房主显示的局域网地址 → 选择坦克并全员准备 → 房主开始对局。每个联机窗口使用玩家 1 的按键控制自己的坦克。

“多人作战”现分为两个独立入口：局域网联机负责本机开房和 UDP 自动发现；服务器联机负责公网地址、口令和服务器房间列表。两条路径进入房间后共用同一权威服务器协议。

启动时会尝试播放 `assets/opening.mp4` 作为全屏片头，视频按窗口比例适配；播放结束后显示首页菜单。视频不存在或格式不受支持时直接显示首页，播放期间按 Esc 可跳过；片头播放时菜单背景音乐自动静音，结束后恢复。点击首页「开始游戏」后仍进入准备页。

## 音效与音乐

音效与背景音乐在 `assets/audio/`，由 `tanktrouble.audio.AudioAssets` 程序合成。角色语音与美术素材并非自制，来源见下方「素材来源」一节。

- **音乐**：首页、准备、设置、排行榜播放 `bgm-menu.wav`；战场播放 `bgm-battle.wav`。暂停、商店、部署、强化页不切换音乐，避免开弹窗时音乐突变。
- **音效**（16 个）：开火、敌军开火、命中敌军、被击中、护盾吸收、击毁、金币、补给、脉冲、传送、岩浆、炮塔部署、清场、失败、胜负结算。

音量在设置页分「音乐」「音效」两档，拖动即时生效，保存后写入 `data/settings.properties`。旧版本写的设置文件没有音量字段，会按默认值（音乐 60%、音效 80%）加载，不会重置其他偏好。

音效由 Model 抛出的事件驱动：`TankGameModel` 在每个触发点追加 `GameEvent`（纯数据，不含 JavaFX 类型），View 每帧调用 `drainEvents()` 取走并播放。同一音效有 45ms 重复抑制，防止连续反弹时糊成一片。

想替换某个音色，直接用同名文件覆盖 `assets/audio/` 里的 WAV 即可，不需要改代码；删掉文件则该音效静音。重新生成全部素材：

```bash
javac -encoding UTF-8 -d target/audio-gen src/main/java/tanktrouble/audio/*.java
java -cp target/audio-gen tanktrouble.audio.AudioAssets
```

缺少 `javafx-media` 时游戏静默降级为无声，不会因此无法启动。

美术与语音并非全部自制，来源如下：

## 3.0 综合整合

3.0.2 以机甲界面版本为唯一主线，并入独立服务器房间、准备、聊天、房主踢人、局域网发现和合作讨伐。战场反馈特效覆盖命中、开火、击毁、拾取、护盾、脉冲、传送、金币、岩浆和波次转场；大型场景立绘、双人左右战斗栏、独立雷达和聊天输入已修复。网络模式暂不开放商店、炮塔和局间强化。

## 模式

- **单人突围**：1 对 3；均衡型初始 10 HP，敌人 1 HP。敌人使用 A* 绕障追击，每秒最多开火一次。敌军不会互相伤害；仅在瞄准玩家、弹道无遮挡且前方没有友军时射击。玩家死亡优先判负；敌人全灭立即胜利。
- **双人对决**：本地同屏两名人类玩家，独立选择坦克。自己及所属炮塔的子弹不会伤害自己，包括反弹后的子弹；对手的子弹仍会造成伤害。本版双人是对战，不是合作；不开放商店和单人排行榜。
- **无尽回响**：从 3 个敌人开始，每波增加，最多同时 10 个；每 4 波提高敌人装甲。清场后有 5 秒拾取窗口，随后选择一个永久强化，再生成新地图。暂停页或强化页可撤离并保存成绩。
- **多人混战**：2–5 名玩家各自为营，不生成 AI 敌人；服务器统一结算移动、弹道和伤害，最后存活的玩家获胜。
- **合作讨伐**：2–5 名玩家属于同一阵营，不会互相造成伤害；开局生成一辆强化 Boss，生命值为 `40 + 10 × 玩家数`，并周期性向周围释放环形炮弹。击毁 Boss 全队胜利，全员阵亡则失败。

## 敌军行为

参考提供的「试做2.0」项目，敌人会检测 250px 内迎面飞来的玩家或玩家炮塔子弹，向弹道侧面躲避。选方向前检查墙体和其他坦克占用的空间，一次躲避保持约 0.48 秒，避免左右反复切换；开火后会短暂侧移，再恢复追击。持续前进受阻时会直线倒车脱困，传送后重置旧路线与躲避状态。

自己及友军的子弹不会触发敌人躲避；敌军子弹也不会命中同阵营敌军，即使发射者已经被击毁。双人对战仍能攻击对手。躲避只根据当前弹道判断，不预测后续反弹，也不保证能避开近距离或多方向夹击。

## 新玩法：反弹蓄能与局间构筑

每枚玩家子弹每次反弹获得 6 点能量，100 点可释放一次共振脉冲：清除附近子弹，对无遮挡且无护盾的其他坦克造成 1 点伤害，并获得 0.8 秒护盾。脉冲会消耗全部能量，也会清除自己的子弹；伤害不会穿墙。玩家可通过反弹路线积累能量，在包围中清弹突围。

无尽强化三选一：

- **复合装甲**：生命上限 +2，恢复 4 HP。
- **超频火控**：永久装填间隔乘 0.86，最低为原始间隔的 35%。
- **共振核心**：立即充满能量，每次反弹额外 +2 能量，脉冲半径 +20px；叠加最多 6 次。

这套机制支持装甲生存、持续火力、反弹脉冲三种成长方向。自动炮塔发射的子弹也可为部署者蓄能。

| 开福 · 白鸢医疗 | 11 | 156px/s | 560ms | 开局护盾 2.5 秒；维修 +4 HP |

完整职责、视觉方向与平衡关系见 `docs/tank-roster-design.md`。

敌人死亡当 Tick 掉落一枚金币；拾取获得 1 金币、10 分。未拾取金币不自动计分；消费只减少金币，不扣分。单人最后一名敌人死亡后立即结算，保留说明书的“最后金币不自动计分”规则。

每张地图有随机位置的维修、护盾和急速补给，敌人死亡还有 28% 概率掉落随机补给。图标分别为 `+`、`O`、`>`、`T`。维修回 3 HP；护盾免伤 9 秒；急速装填间隔减少 45%，持续 9 秒。商店价格为 2 / 3 / 3 / 4 金币。打开商店后，战斗和效果计时一起暂停。

**炮塔部署**：购买或拾取炮塔后先加入库存，不立即计时。在商店或战斗侧栏点击「部署炮塔」（战斗中也可按 T），再用鼠标左键选择战场位置。绿色预览可放置，红色表示与墙、坦克、炮塔或传送门重叠；右键、Esc 或「取消部署」可取消。部署过程暂停战斗，无效位置不消耗库存。成功后回到暂停页，点击「继续战斗」开始计时：普通炮塔 12 秒，工程型 18 秒。库存与已部署炮塔合计最多 3 座，未部署库存保留到下一波，新一局清空。所有模式均免疫自己及所属炮塔的子弹。

传送门 A/B 双向传送坦克，冷却 1.5 秒；出口被占用时不传送。子弹不通过传送门。冰面保留玩家移动惯性，岩浆每连续停留 1 秒造成 1 HP 伤害，重力区降低玩家移动速度。三种地形开局各随机生成一块，每隔 10 秒战斗时间一起刷新到新的随机位置，避开坦克、炮塔、传送门和补给。暂停、商店、部署及升级选择时不计时；新局和新波次重新计时。特殊地形可在开局前关闭。

## 保存与技术结构

战绩存于游戏目录 `data/leaderboard.properties`，采用临时文件加原子替换，最多保留 30 条，按积分、波次、耗时排序；通过 `-Dtanktrouble.dataDir=目录` 可更换保存位置。联机为同版本客户端之间的局域网 TCP 对战，不依赖账号或云服务。

```text
src/main/java/tanktrouble/
  App.java                    启动入口
  controller/GameController   按键转换、固定步长累加器
  model/api/GameModel          游戏接口
  model/core/TankGameModel     状态、波次、道具、结算
  model/data/                  不可变快照、枚举、数值
  model/entity/                仅供仿真修改的实体
  model/map/                   Prim 迷宫、JGraphT A*
  model/rule/                  AI、扫掠 AABB、弹道
  model/persistence/           本地排行榜
  net/                         权威服务器、客户端、房间、协议与局域网发现
  audio/                       音效合成、素材生成、播放与反射降级
  view/                       JavaFX 窗口、Canvas 绘制、中文标签
```

Model 不导入 JavaFX。View 只读快照并发送命令，Controller 不结算伤害或金币。音频通过事件流从 Model 单向传给 View，`audio/Clips` 是唯一接触 `javafx.scene.media` 的地方，且全部走反射。核心仿真固定 `tick(8)`，单帧最多补算 50ms。坦克碰撞为 32×32 AABB，炮口按角度计算安全出膛位置，子弹第 6 次反弹销毁，另有 10 秒寿命上限。

当前界面采用校园卡通主题：首页为等距校园插画、描边标题和立体菜单；准备、设置、排行榜、补给及战斗页面统一草绿与红砖配色。首页保留后续开场动画的接入位置，目前点击开始直接进入准备页。

详细设计差异与验证范围见 `DEVELOPMENT.md`。当前版提供程序绘制的校园、坦克、战场、地形、脉冲效果，以及程序合成的音效与音乐。音频音色尚未经过人工试听调整，长期数值平衡也仍需要真实试玩反馈。
