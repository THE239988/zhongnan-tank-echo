坦克大战 3.0.2 · 独立服务器
====================

一、启动
    ./start-server.sh 你的口令
    ./start-server.sh 你的口令 7777      # 指定端口

    systemd 部署可使用 /etc/tank-trouble.env：
    TANKTROUBLE_PASSWORD=你的口令
    TANKTROUBLE_PORT=7777

窗口不要关，关掉服务器就停了。

二、玩家怎么连
    双击 run.bat → 首页「多人作战」→ 填服务器 IP、端口 7777、口令 → 连接
    连上后看到房间列表，可以自己建房或进别人的房。

三、容量（实测）
    上限 5 个房间 × 每房 5 人
    5 房满员对局时：服务端 CPU 约 85% 单核，存活内存约 3 MB

    这台 2 核机器跑满 5 房是吃力的；只开 1~2 房时占用低得多。

四、要求
    Java 17+（已在 Java 21 验证）
    安全组/防火墙放行 TCP 7777
